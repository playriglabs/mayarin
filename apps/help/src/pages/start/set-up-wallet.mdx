title: Set up your wallet
description: "Choose where your money lands. You can connect your own wallet or let Mayarin create a managed one."
---

Your wallet is the address that receives your settlement. Open **Wallets** in the sidebar. You need the `wallets:withdraw` permission to see it.

## Pick one

| Option                      | Choose it when                                              |
| --------------------------- | ----------------------------------------------------------- |
| **Connect an existing wallet** | You already have a wallet (for example MetaMask) and want payments there. |
| **Managed wallet**          | You have never held a wallet. Mayarin creates one for you, and you are an owner of it from the start. |
| **Solana address**          | You want to be paid on Solana. Connect Phantom, or enter an address and complete the proof manually. |

An EVM address is the same on every EVM network, so one address covers them all.

## Prove it is yours

Connecting a wallet asks you to sign a short message. Signing costs nothing and moves no money. It proves you control the address, and a wallet is only payable once verified.

If you see **That signature did not verify**, reconnect and sign again with the same account that owns the address.

## Self-custody

Mayarin is never the only owner of a managed wallet, and you can remove Mayarin as an owner without our help. The money is yours from the first payment.
