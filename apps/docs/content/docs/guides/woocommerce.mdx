---
title: WooCommerce
description: Install the Mayarin gateway, connect your merchant credentials, and receive payment status updates.
---

The WooCommerce plugin is the reference integration for a production storefront. It creates a Mayarin payment link, redirects the buyer to hosted checkout, and uses signed webhooks to update the order.

Keep the secret key and webhook signing secret in WordPress server configuration. Do not add either value to storefront JavaScript or theme templates.

See the repository's `docs/woocommerce.md` and `plugins/woocommerce` package for installation and testnet verification details while the public plugin distribution is prepared.
